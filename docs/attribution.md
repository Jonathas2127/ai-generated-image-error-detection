# Attribution and reuse

## Original contribution

Error Detection in AI-Generated Images was an independent undergraduate project by [Jonathas2127](https://github.com/Jonathas2127), July 2024–May 2025. The portfolio material attributes task formulation, data annotation, prompt experiments, model API integration, evaluation and analysis to the project author. Repository organization and the dependency-free offline evaluator were added in November 2026.

The project uses pretrained models. It does not claim authorship of model weights, the Groq API, third-party libraries, Reddit images or the data collection tool.

## Collection tool

Data collection used [RaccoonTamer/Reddit-Crawler](https://github.com/RaccoonTamer/Reddit-Crawler). The local third-party copy carries an MIT license with copyright 2023 RaccoonTamer. Its source code and downloaded media are not redistributed here. Any future redistribution should preserve its license and notices.

## Images, references and licenses

No rights to original Reddit images are asserted or granted. Images and image-containing reports/slides are excluded from this repository. Papers referenced by the original project are not redistributed.

An open-source license for the author's original source code and a reuse license for the annotation/prediction files have not been selected. Public visibility should not be interpreted as a blanket grant of reuse rights. Refer to [GitHub's licensing guidance](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/licensing-a-repository).
